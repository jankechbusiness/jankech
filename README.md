# Jankech Web Showcase

Implement the requested portfolio website for Jankech Web now; use internal planning and do not present another implementation plan for user approval.

### Specification & Requirements (from attached file):
Vytvoř moderní osobní portfolio web pro značku „Jankech Web“. Jsem AI web designer a pomáhám malým lokálním firmám získat více kvalitních poptávek skrze moderní web, SEO, automatizace a správu online prezentace.

Použij přiložené logo značky (logo.png).

Web má být primárně v češtině, s viditelným funkčním přepínačem CZ / EN, který přeloží celý obsah do angličtiny. Design má být čistý, minimalistický, přátelský, moderní a přístupný. Inspiruj se dynamikou a prémiovým dojmem webů janslovi.com a landonorris.com, ale nevytvářej jejich kopii.

Barevná paleta:
- černá a bílá jako základ
- výrazná modrá #1D4ED8 jako hlavní akcent
- jemné šedé odstíny pro pozadí a texty

Vizuální styl & technické požadavky:
- Výrazná moderní typografie, dostatek volného prostoru, plynulé hover efekty a střídmé scroll animace.
- V pozadí jemný abstraktní dynamický efekt v modrých odstínech, který neruší čitelnost.
- Plně responzivní a optimalizované pro mobilní zařízení.

Struktura webu:
1. Navigace:
   - Logo „Jankech Web“ vlevo (využij přiložený obrázek logo.png).
   - Odkazy: Služby, Projekty, Proces, Ceník, Kontakt.
   - Přepínač jazyků CZ / EN.
   - Vpravo výrazné CTA tlačítko „Nezávazně poptat web“ s plynulým scrollem na formulář.

2. Hero sekce:
   - Hlavní nadpis: „Z návštěv na poptávky.“
   - Osobní text: „Jsem Jankech a pomáhám malým lokálním firmám proměnit jejich web v nástroj, který buduje důvěru a přivádí nové zákazníky.“
   - CTA tlačítko „Nezávazně poptat web“.
   - Vedle textu moderní abstraktní AI vizuál v barvách značky.

3. Sekce pro malé lokální firmy:
   - Obecný text bez konkrétních profesí.
   - Web nemá pouze dobře vypadat, ale má budovat důvěru, jasně ukazovat hodnotu firmy a přeměňovat návštěvníky na kontakty.

4. Sekce „Proč si poptat spolupráci“:
   - 4 elegantní karty s konzistentními ikonami/ilustracemi:
     1. Více kvalitních poptávek
     2. Moderní první dojem
     3. Méně ruční práce díky automatizaci
     4. Lepší dohledatelnost díky SEO a Google Business Profile
   - Každá karta s krátkým, srozumitelným vysvětlením.

5. Služby:
   - Karty s jemným hover efektem:
     - Tvorba a redesign webů
     - SEO
     - Správu a údržbu webu
     - Automatizace formulářů a kalendářů
     - Google Business Profile

6. Projekty:
   - 2 velké projektové karty s AI obrázky / mockupy:
     - Web pro osobní stylistku
     - Web pro malířskou firmu
   - Obsah: obrázek, název, krátký popis, výrazné tlačítko „Zobrazit projekt ↗“.
   - Po kliknutí otevření elegantního modalu s větším náhledem a detailnějším popisem.
   - Texty a obrázky snadno upravitelné v kódu.

7. Proces spolupráce:
   - Vizuálně výrazná sekce ve tvaru organické modré linky („hada“) procházející stránkou, která se při scrollování plynule vykresluje a zvýrazňuje aktivní krok.
   - 6 kroků (velký text + vysvětlení):
     1. Odešlete poptávku — Napíšete pár informací o svém podnikání a cílech.
     2. Projdeme možnosti — Ozvu se vám; domluvíme hovor nebo vám pošlu otázky.
     3. Vznikne návrh — Připravím moderní návrh webu podle vašeho byznysu.
     4. Doladíme detaily — Společně upravíme vše, aby web seděl vaší značce.
     5. Spustíme web — Dodám funkční web připravený přivádět poptávky.
     6. Rosteme dál — Zůstáváme ve spojení pro správu, úpravy a další růst.

8. Orientační cena:
   - Nadpis: „Investice do webu, který pracuje za vás.“
   - Rozpětí: „Weby na míru od 5 000 do 20 000 Kč.“
   - Informace, že konečná cena závisí na rozsahu projektu.

9. Reference:
   - Ukázkové AI avatary a ilustrační reference s badge/označením jako ukázkový obsah pro snadné nahrazení.

10. O mně:
    - Osobní sekce o moderním přístupu, inovacích, designu zaměřeném na konverze a výsledky pro lokální firmy.

11. Kontakt a poptávkový formulář:
    - Pole: Jméno, E-mail, Telefon, Obor firmy, Popis zadání / co klient potřebuje, Odkaz na současný web, Možnost přiložit soubor.
    - Validace formuláře a elegantní potvrzovací stav po odeslání: „Děkuji za poptávku. Ozvu se vám co nejdříve.“

      - E-mail: jankechbusiness@gmail.com

    - Formulář odesílá data / připravuje notifikaci pro jankechbusiness@gmail.com.
